# Kolluru Yashwanth — Portfolio

A single-page personal portfolio built with semantic HTML, a CSS variable-based
color and type system, Flexbox, and CSS Grid.

## Live site

https://yashwanthk26301053-wq.github.io/DevFolio/


## Run locally

```bash
git clone https://github.com/yashwanthk26301053-wq/devfolio.git
cd devfolio
```

Then just open `index.html` in your browser. That's it.

## Built with

- Semantic HTML5 (`header`, `main`, `section`, `footer`)
- CSS custom properties for color and typography
- Flexbox (header/nav) and CSS Grid (project cards)
- One responsive breakpoint (`@media (min-width: ...)`)
- Deployed with GitHub Pages

Repository URL: https://github.com/yashwanthk26301053-wq/devfolio
